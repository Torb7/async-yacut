# YaCut

YaCut — веб-сервис для сокращения ссылок. Пользователь может указать собственный короткий идентификатор или получить сгенерированную сервисом ссылку. При переходе по короткому адресу сервис перенаправляет пользователя на исходный URL.

Дополнительно YaCut позволяет выбрать несколько файлов, асинхронно загрузить их на Яндекс Диск и получить отдельную короткую ссылку для скачивания каждого файла.

## Возможности

- создание коротких ссылок через веб-интерфейс и API;
- пользовательский короткий идентификатор длиной от 1 до 16 символов;
- автоматическая генерация уникального идентификатора длиной 6 символов из латинских букв и цифр;
- запрет повторного использования идентификаторов и адреса `/files`;
- загрузка нескольких файлов на Яндекс Диск одновременно;
- асинхронное взаимодействие с Яндекс Диском через `aiohttp`;
- перенаправление по коротким ссылкам и скачивание загруженных файлов;
- собственные HTML-страницы ошибок 404 и 500;
- JSON-обработчики ошибок API.

## Стек

## Установка и запуск

Клонируйте репозиторий и перейдите в его директорию:

```bash
git clone https://github.com/Torb7/async-yacut
cd async-yacut
```

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
```

В Windows команда активации может выглядеть так:

```powershell
venv\Scripts\activate
```

Установите зависимости:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Создайте в корне проекта файл `.env`:

```dotenv
FLASK_APP=yacut
FLASK_ENV=development
SECRET_KEY=<secret_key>
DATABASE_URI=sqlite:///db.sqlite3
DISK_TOKEN=<OAuth-токен-Яндекс-Диска>
```

Переменные используются следующим образом:

| Переменная | Назначение |
| --- | --- |
| `FLASK_APP` | Точка входа Flask-приложения, `yacut` |
| `SECRET_KEY` | Секретный ключ Flask и защита форм CSRF |
| `DATABASE_URI` | Строка подключения к базе данных; для SQLite используется `sqlite:///db.sqlite3` |
| `DISK_TOKEN` | OAuth-токен для доступа к API Яндекс Диска |

Примените миграции и запустите сервер:

```bash
flask db upgrade
flask run
```

После запуска приложение доступно по адресу <http://127.0.0.1:5000/>.

Для работы страницы загрузки файлов `/files` необходимо указать действительный `DISK_TOKEN`. Для создания коротких ссылок и работы API токен Яндекс Диска не требуется.

## Веб-интерфейс

- `/` — создание короткой ссылки. Поле исходного URL обязательно, поле пользовательского идентификатора — опционально.
- `/files` — выбор и загрузка нескольких файлов на Яндекс Диск. Кастомные идентификаторы для файлов не задаются: сервис генерирует их автоматически.
- `/<short_id>` — переход по короткому идентификатору. Для ссылки на внешний ресурс выполняется перенаправление, для файла — скачивание по ссылке Яндекс Диска.

Если пользовательский идентификатор уже существует, содержит недопустимые символы, длиннее 16 символов или равен `files`, новая запись не создаётся, а пользователь получает сообщение об ошибке.

## API

Спецификация API находится в файле [`openapi.yml`](openapi.yml).
### Создание короткой ссылки

`POST /api/id/`

Тело запроса — JSON с обязательным полем `url` и необязательным `custom_id`:

```json
{
  "url": "https://www.python.org/",
  "custom_id": "python"
}
```

Успешный ответ имеет статус `201 Created`:

```json
{
  "url": "https://www.python.org/",
  "short_link": "http://127.0.0.1:5000/python"
}
```

Если `custom_id` не передан или пуст, сервис генерирует его автоматически.

### Получение исходной ссылки

`GET /api/id/<short_id>/`

Пример ответа со статусом `200 OK`:

```json
{
  "url": "https://www.python.org/"
}
```

Ошибки API возвращаются в JSON-формате:

```json
{
  "message": "Указанный id не найден"
}
```

Документацию можно визуализировать в [Swagger Editor](https://editor.swagger.io/), загрузив файл `openapi.yml`.

## Структура проекта

```text
async-yacut/
├── migrations/              # миграции базы данных
├── yacut/
│   ├── api_views.py          # API-эндпоинты
│   ├── error_handlers.py     # обработчики ошибок
│   ├── forms.py              # формы веб-интерфейса
│   ├── models.py             # модель URLMap и генерация идентификаторов
│   ├── views.py              # HTML-маршруты
│   └── yandex_disk.py         # асинхронная загрузка файлов
├── openapi.yml               # спецификация API
├── requirements.txt          # зависимости
└── settings.py               # конфигурация приложения
```

Основная модель `URLMap` хранит исходную ссылку (`original`), короткий идентификатор (`short`), первичный ключ (`id`) и время создания записи (`timestamp`).
